Quiet interfaces.

A reusable technical branding guide for future products: color system, typography, component forms, layout behavior, motion, dark mode, and agent-ready implementation rules.

01 · FOUNDATION

Calm by default.
Expressive on purpose.

The interface should remain mostly neutral. Stronger visual energy should appear only in intentional moments: hero sections, technical showcases, AI surfaces, visualizations, and key transitions.

Canvas

Clean base

White or near-white is the main canvas for clarity and calm hierarchy.

Support surface

Soft structure

Use subtle gray sections or panels to separate content without visual clutter.

Functional blue

Interactive accent

Use for links, active states, focus, and carefully selected primary emphasis.

Dark showcase

Immersive utility

Use near-black surfaces for technical moments, code previews, dashboards, or focused product highlights.

Decorative spectrum

Brand energy

Reserve spectral accents for halos, particles, visual identity, and selected visualizations—not for everything.

02 · LIGHT & DARK

Two complete themes.
One coherent system.

Light mode is the default workspace. Dark mode is a deliberate focused mode with careful contrast, not a crude inversion.

Theme behavior

Both themes preserve the same spacing rhythm, radius family, typography hierarchy, and component behavior. Only the visual environment changes.

04 · AGENT RULES

Reusable by humans.
Executable by agents.

01
Tokenize first.
Map colors, spacing, radius, type, and motion to semantic tokens before rebranding screens.
02
Implement both themes.
Support light and dark as first-class themes.
03
Start with primitives.
Buttons, inputs, cards, tables, nav, modals, then higher-level pages.
04
Preserve functionality.
This is a UX/UI rebrand, not a silent logic rewrite.
05
Keep charts restrained.
Readable, meaningful, and low-noise visualizations only.
06
Respect accessibility.
Contrast, focus states, hit targets, keyboard support, and reduced motion are mandatory.
